TradePilot 1.0.0 is the first public release of the TradePilot desktop trading terminal for Delta Exchange perpetual futures.

## What's in it

- **Strategies from plain-language prompts.**
  - Describe a strategy in your own words. Anthropic Claude or OpenAI proposes rules and asks about anything missing or unclear.
  - TradePilot validates the rules, explains them in plain language, and flags anything it cannot implement instead of quietly changing it.
  - You confirm before anything is saved.
  - Changes are made the same way and kept as versions.
- **Backtesting** on Delta Exchange history, with fees and configurable slippage. Results are clearly labelled as simulated.
- **Paper trading**, simulated on live market data, and **live automated trading** on Delta Exchange:
  - risk limits per strategy and per account
  - duplicate-order prevention
  - reconciliation with the exchange
  - an emergency stop

  Live trading is **off** until you configure the exchange connection and risk settings, type a confirmation phrase and enter your password.
- **Real-time market data**, account balance, and email and WhatsApp trade alerts.
- **Security:**
  - password-protected app with auto-lock
  - API keys encrypted with your operating system's credential store
  - the trading engine never sees your credentials
- **Automatic updates**, verified before they install, on Windows and Linux.

## Installing

- **Windows.** Run the installer. This release is not code-signed, so Windows SmartScreen may show *"Windows protected your PC"*: choose **More info → Run anyway**.
- **Linux AppImage:**
  1. `chmod +x TradePilot-1.0.0-x86_64.AppImage`
  2. `./TradePilot-1.0.0-x86_64.AppImage`

  On Ubuntu 22.04 or later, install `libfuse2` (`libfuse2t64` on 24.04) if the AppImage does not start.
- **Linux .deb.** `sudo apt install ./tradepilot_1.0.0_amd64.deb`, then start *TradePilot* from the applications menu.
- **macOS:**
  1. Open the `.dmg` and drag TradePilot to Applications.
  2. This release is not signed with an Apple Developer ID, so the first time, right-click TradePilot → **Open** → **Open**.
  3. If macOS says the app "is damaged", run `xattr -cr /Applications/TradePilot.app` in Terminal and open it again.

On first launch you create the password that protects the app on this computer. To store API keys, Linux needs a desktop keyring (GNOME Keyring or KWallet); without one, TradePilot refuses to store keys rather than saving them unencrypted.

## Upgrading

- **Windows and Linux** (AppImage and .deb). Later versions are found automatically. They download in the background and install when you choose **Restart and install** in Settings → Updates, or the next time TradePilot quits.
- **macOS.** Download the new `.dmg` from this page and replace the app in Applications. Unsigned macOS builds cannot update themselves.
- **Your data.** Your password, strategies, settings and history are kept across upgrades. The database is backed up automatically before any change to its format.

## Known limitations

- **Subscription server not connected.** This build has no subscription server configured. The app says *"Server not configured"*, and the 72-hour trial and the $20/month and $500 lifetime plans cannot be activated yet. Features that require a subscription (creating and running strategies, backtesting, paper and live trading) stay locked. A later release, built after the server is deployed, enables them.
- **Unsigned installers.** Windows and macOS installers are not code-signed: you will see the security prompts described above, and macOS does not auto-update.
- **Exchange and AI connections are not verified by us.** Live order placement has been tested against Delta Exchange's documented API and a scripted exchange in automated tests. It has not been run against a real or testnet account by the developers. Start with paper trading, then the Delta Exchange India testnet.
- **The AI can misread a prompt.** AI-interpreted strategies can be wrong even after validation. Review the rules, backtest and paper trade before using real funds.
- **Strategy scope.** One instrument, one timeframe and one open position per strategy. No trailing stops, time-based exits, or indicators beyond SMA, EMA, RSI, ATR, Bollinger bands and highest high / lowest low.
- **Architectures.** Builds are 64-bit only: x64 for Windows and Linux; arm64 and x64 for macOS.

Trading derivatives carries a high risk of loss. TradePilot is a tool, not financial advice.
